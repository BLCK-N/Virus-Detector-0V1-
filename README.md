## What it does

Virus Detector is a desktop security tool that scans your PC and files for threats.

- **System scan** — scan your entire PC with Quick Scan or Full Scan
- **File analyzer** — browse or drop any file to check if it contains a virus
- **Real-time protection** — see if your antivirus is active at a glance
- **Signature version** — check your antivirus signature version and last update
- **Scan report** — view the latest scan results in a clear layout
